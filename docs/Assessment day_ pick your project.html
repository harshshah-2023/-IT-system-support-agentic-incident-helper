Jargon in plain words

The terms you’ll hear on assessment day, without the technical wrapping.

Agent
An AI assistant that can decide to use tools, not just chat.
Tool
A small function the assistant can call, like “look up order” or “calculate refund”.
Thread
One separate conversation. Two customers means two threads, and neither can see the other’s.
Vector search (Task 3A)
Finds paragraphs that mean something similar to the question, then answers from them with page numbers.
Contents-page search (Task 3B)
The AI reads the table of contents and opens the right chapter, like a person flipping through a book. It shows the path it took.
Guardrail
A check that runs before the AI sees a message: it hides private details and stops trick instructions.
Human in the loop
The workflow freezes before a risky step and waits for a person to approve, edit or reject it.
AI judge
A second AI that marks answers against an answer key of six questions, and explains its marks.
Fallback
A backup model that takes over if the main one fails or is too busy.
Cache
Saved answers, so the same question asked twice is answered instantly and for free.

Ground rules for assessment day

These apply whichever project your team picks.

  • Use your own document15+ pages, assigned by the reviewer. Examples from the course video aren’t allowed.
  • Keep one tidy code folderA Git repository with setup files and an example settings file. No passwords or API keys in the code.
  • Human approval must be a real pauseUse LangGraph’s built-in interrupt. A typed yes/no prompt inside the code is an automatic fail.
  • Expect a 15-minute live defenceThe reviewer changes something on the spot, like deleting a file or breaking a key, and asks you to explain what happens.
